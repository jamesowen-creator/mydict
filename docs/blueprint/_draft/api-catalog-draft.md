## 공통 사항 (모든 행에 적용)

- 모든 `/api/**` 요청은 먼저 `createApiReadyGate`(server.js:68, 구현 lib/db.js:737)를 지난다. DB 초기화가 끝날 때까지 최대 15초 기다린다.
- 미들웨어 순서(server.js:37-45): cors → express.json(1mb) → session → passport. 라우터 뒤에 errorHandler(server.js:82).
- **requireAuth 는 매 요청마다 users 를 읽는다**(middleware/auth.js:30). 그래서 인증이 있는 행의 DB 읽기에는 모두 `users(middleware/auth.js:30)` 가 들어 있다. requireAdmin 은 requireAuth 를 부른 뒤 role 을 본다(middleware/auth.js:46-52).
- `checkPermission`(middleware/auth.js:60)은 users 의 한 열을 읽는다(:64). DB 오류·행 없음이면 허용(fail-open). Speak Loop·문장 학습·개념 지도·대결은 별도 fail-closed 검사를 쓴다(각 행 참조).
- 사용량 기록 `trackUsage`(lib/db.js:726)는 api_usage 에 INSERT 한다(:729). 표의 "api_usage(trackUsage)" 는 이것이다. 하루 한도 확인은 api_usage SELECT 다.
- 열 안의 파일 표기: `:N` 만 있으면 그 행 "정의" 파일, `middleware/auth.js`·`lib/…`·`routes/…` 는 파일 이름이 앞에 붙는다. 근거 표시는 행 단위다([확인함]은 적힌 줄을 직접 읽음).
- 엔진·외부 이름은 LEGEND 3·4절 이름을 쓴다. "엔진 / 외부" 순서. LEGEND 설명 범위를 벗어나는 것은 아래 (마)에 모았다.
- "호출 화면" 의 공용은 모든 화면이 읽어 들이는 public/js/common/authGate.js·appHeader.js 가 부르는 것이다(홈은 자체 코드 사용).

## 조사 방법과 한계

- 라우트: server.js 와 routes/*.js 에서 `router|app . get|post|put|patch|delete(` 를 grep 했고, `router.route`·`router.param`·`app.all` 이 없음을 확인했다. 등록 순서는 server.js:70-80 의 `app.use(require(routes/…))` 11개.
- DB·캐시·엔진: 각 라우트 본문과 호출하는 lib 함수(lib/db.js trackUsage, gloss_backfill, jgrammar, speakloop_*, cmap_*)를 따라가며 SQL·fetch·messages.create 줄을 확인했다. 음성 학습의 연결 분석·그림 파이프라인처럼 응답 뒤 백그라운드로 도는 함수는 SQL·호출 줄을 grep 으로 찾아 적었다(그림 파이프라인 행은 [추정]).
- 테이블 이름이 문자열 조합으로 정해지는 곳은 없었다. 조합되는 것은 users 의 열 이름뿐이다(routes/admin.js:53 허용 목록 안, middleware/auth.js:64 코드에 고정된 perm 이름). 그래서 [미확인] 은 0건이다.
- 호출 화면: public/**/*.js·*.html·home-wheel/src 의 `/api/`·`/auth/` 문자열과 `fetch(`·`api(` 호출을 모두 훑었다. 이어붙인 경로(`/api/voice-notes/` + id + `/links` 같은 것)는 줄을 읽어 라우트에 맞췄다. 홈은 빌드 결과(public/home/assets/index-CPcsUBip.js:40, 한 줄로 압축됨)와 원본(home-wheel/src)을 함께 적었다.
- 화면 이름은 screens/*.md 의 12개 기준이다. 공용 모듈(authGate.js·appHeader.js)이 부르는 `/api/me`·`/auth/google` 은 "공용"으로 적었다.
- public/sw.js 에는 `/api/`·`/auth/` 경로 판별 문자열만 있고 fetch 호출 대상이 아니다(public/sw.js:44).
