항목을 누르면 연결된 항목이 강조되고 나머지는 흐려집니다. 같은 항목을 다시 누르면 해제됩니다. 화면을 누르면 동작별 흐름이 상세 상자(넓은 화면은 오른쪽, 좁은 화면은 목록 아래)에 나오고, 동작 카드를 누르면 왼쪽 목록에 순서 번호가 붙습니다.

화면 엔진 DB 캐시 기기 API 외부 모듈 필요 미작성 관계: →호출 · →읽기 · →쓰기 · →이동(화면→화면) · ⇢대체(앞이 실패하면 뒤, 같은 번호의 a·b 가지) · →필요(로그인·권한). 모양: 화면=둥근 사각, 엔진=육각형, DB=원통, 캐시=점선 윗면 원통, 기기=점선 알약, API=가는 사각, 외부=점선 사각, 모듈=직각 사각, 필요=파선 알약, 미작성=회색 점선. 동작 카드·번호 배지는 ①②③ 순서입니다.
