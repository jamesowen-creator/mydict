# 디자인 요청 프롬프트 템플릿

새 화면을 이 스타일로 디자인해달라고 할 때 아래 틀을 채워서 사용.
`docs/design/design-principles.md`를 함께 참고하도록 지시하면 톤이
일관되게 유지된다.

---

[화면 이름]을 디자인해줘.

디자인 방향: `docs/design/design-principles.md`의 원칙을 따라줘
(미니멀, 카드/뱃지 없음, 검색창·주요 버튼에만 radius, 선택 상태는
굵기+밑줄, 포인트 컬러 최소 1개, 라이트/다크 모드 둘 다 고려).

화면 구성:
- [헤더에 들어갈 요소]
- [핵심 입력/액션 요소]
- [본문에 표시할 정보와 우선순위]
- [하단 네비게이션/보조 요소]

기능적으로 유지해야 하는 것 (기존 화면이 있는 경우):
- [실제 앱에 이미 있는 기능 중 절대 빠지면 안 되는 것 나열]

사용성 기준:
- 가장 중요한 기능이 화면에서 먼저 보이게
- 본문 글자는 작지 않게, 긴 설명도 편하게 읽히도록
- 터치 영역 44px 이상
- 작은 화면에서도 반응형으로 잘 보이게
- 라이트/다크 모드 둘 다 고려

---

## 사용 팁
- 실제 화면 스크린샷이 있으면 같이 첨부 — "기능은 이 스크린샷대로
  유지하고 디자인만 원칙대로 바꿔줘"라고 하면 정확도가 올라감
- 한 번에 여러 화면을 요청하지 말고 화면 하나씩 확정한 뒤 다음으로
  넘어가는 게 수정 범위를 좁히는 데 유리함
