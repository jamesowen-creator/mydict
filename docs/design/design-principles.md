# METIS-3 디자인 원칙 (확정)

확정일: 2026-10-10 (사용자 결정). 기준: **언어 사전 화면(english_dictionary.html)의 실제 값**. 근거 집계는 docs/design/current-state-census.md(238-2). 이 문서가 이전 원칙 문서(커밋 f19dac1)를 대체한다.

## 원칙
1. 박스를 줄이고 텍스트 중심으로 쓴다. 눌러야 할 주 동작만 코랄 채움 버튼을 쓴다.
2. 값은 언어 사전 화면 기준으로 통일한다. 사전에서 한 역할이 두 값이면 밝은 쪽을 쓴다. 단 **글자색**이 배경 대비 4.5:1 미만이 되면 글자에만 진한 쪽을 쓴다(예외). 면·선·큰 요소는 밝은 쪽을 그대로 쓴다.
3. 다크 모드는 쓰지 않는다.
4. 새 화면과 수정하는 부분은 이 문서를 따른다. 기존 코드는 일괄 치환하지 않고, 해당 부분을 수정할 때 맞춘다.

## 간격
- 허용 단계(px): 0 · 4 · 8 · 10 · 12 · 16 · 20 · 24.
- 6·14·2px 등 단계 밖 값은 일괄 변경하지 않고, 해당 부분을 수정할 때 가까운 단계로 맞춘다.

## 모서리
- 0: 기본(박스 없음). 10px: 버튼·입력창·검색창·칩. 16px: 카드. 50%: 원형.
- 알약(20px, 999px)과 2·4·8·12·14·24·40px는 정리 후보다. 새로 쓰지 않는다.

## 그림자
- 사전 방식을 유지한다: 하단 내비 `0 -2px 8px` 코랄 7%, 결과 카드 `0 4px 20px` 코랄 8%, 포커스 링 3px 코랄 25%. 새 그림자 종류를 늘리지 않는다.

## 레이아웃
- 최대 폭 680px, 좌우 여백 16px, 공용 헤더 65px, 제목 바 56px, 하단 내비 78px, 터치 영역 최소 44px. 중단점 460px.

## 버튼 (216~217 규칙 유지)
- 보조 동작: 박스 없는 밑줄 텍스트 `.btn.text`(높이 44px).
- 주 동작: 코랄 채움 `.btn`(배경 #b8442e, 흰 글자, 14px, 모서리 10px, padding 12px 20px).
- 확인창을 거치는 위험 동작: `.btn.text.danger`.
- 표시용 뱃지는 박스·알약으로 만들지 않는다. 허용 목록(의미상 박스): `.tl-bar`, `.rec-btn`.
- 사전 화면에 남은 박스·알약 버튼(.wb-side-btn, .wb-sort-btn, 팟캐스트·OCR 원형 등)은 선택 상태 표시 문제가 있어 별도 검토 후 정리한다.

## 입력창
- 흰 면, 1px #dde2f5 선, 모서리 10px, 글자 16px, 포커스는 코랄 링.

## 유지하는 기존 규칙 (이전 원칙 문서에서 이어받음)
- 아이콘은 인라인 stroke SVG만 사용, 이모지(국기 포함) 사용 금지
- 선택/활성 상태는 색상 단독이 아니라 굵기+밑줄(또는 굵기+아이콘 변화) 등 최소 2가지 신호로 표현
- 카운트 표시(뱃지 숫자 등)는 빨간 원형 뱃지 대신 라벨 옆 작은 보조색 숫자로
- 클릭 요소는 실제 `button` 또는 `a`를 쓴다.

## 접근성
- 글자 대비 4.5:1 이상. 터치 영역 44px 이상.
- 선 #dde2f5는 흰·페이지 배경 대비가 1.2~1.3배라 비텍스트 대비 3:1에 못 미친다. 구분선은 장식 용도로 두고, 입력창 테두리 개선은 열린 항목이다.

## 현재 코드와 다른 점 (238-2·239-1 집계, 선언 횟수 기준)
- 사전 외 화면의 오류 색은 모두 사전 값과 다르다(문학 7, 한입 6, 과학 6, 개념 7, 음성 11).
- 중립 선 색과 보조 글자색은 문학·한입·과학·음성 전부가 사전 값과 다르다. 개념은 이미 가깝다(선 4/31, 보조 글자 0/37이 다름).
- 본문 글자색은 다른 화면이 #1a1a1a 계열이다(전체 133회).
- 간격은 단계 밖 값이 다른 화면 전체의 약 30%, 사전 자체도 약 34%다.
- 공용 변수 사용 비율은 화면별 0~19%이고 `.btn`, `.btn.text`, `.bottom-nav`, `.msg`는 화면마다 따로 정의돼 있다.

## 열린 항목
- 섹션 라벨은 작은 대문자 스타일(12px, weight 700, letter-spacing, uppercase, 보조색)로 통일(이전 원칙 문서의 규칙): 새 글자 단계표의 12px 캡션과 겹치고 대문자 규칙은 정해지지 않았다.
- 입력창 테두리 대비 개선(위 접근성).
- 알약·단계 밖 모서리·간격의 점진 정리.
- 사전 화면 자체의 값 정리와 공용 CSS 편입 순서.
- 이 문서의 값을 공용 CSS 변수(tokens.css)로 올리는 작업은 아직 하지 않았다.
