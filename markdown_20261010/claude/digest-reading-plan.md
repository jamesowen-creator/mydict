# 한입 독서 — 추후 진행 과제

기준일: 2026-10-05. 상태: 방향만 정함, 착수하지 않음(당장은 이 문서에만 기록).

## 문제 인식 (사용자)
- 줄거리 분량이 글자 수 기준으로만 되어 있어, 장편 소설의 내용이 지나치게 압축됨. (코드로 확인한 것이 아니라 사용자 인식. 현재 기준은 미확인)
- 줄거리가 한 문단으로 이어져 사건 요약에 치중하고, 글의 구조를 파악하기 어려움.

## 사용자 결정 (2026-10-05)
1. 소설 줄거리는 발단-전개-위기-절정-결말 5단계 구조로 구성.
2. 구조는 글의 성격에 따라 정함(5단계가 맞지 않는 작품은 맞는 구성 방식으로 설명).
3. 구조는 문학 갈래에 따라 다르게 정함.
4. "더 보기"로 숨기지 않고, 기본 화면에서부터 구조를 갖춘 형식으로 보여줌.
5. 줄거리 분량은 작품(원작) 분량에 비례하는 구조.
6. 희곡·수필도 반영. 시·시조는 제외.

## 미정 사항
- 희곡·수필의 구조 단위(희곡: 막·장 또는 발단~대단원, 수필: 처음-중간-끝 등).
- 분량 비례 규칙의 수치. 제안 예(미확정): 등급별 목표 범위(단편 500~800자, 중편 1,000~2,000자, 장편 2,500~4,000자, 대하 4,000~6,000자). 고정 비율(예: 2%)은 장편에서 지나치게 길어져 비권장.
- 5단계가 맞지 않는 작품(역순행·액자식·심리 중심)의 표시 방식. 제안: 구성 방식 설명 한 줄 추가.

## 확인 필요
- 현재 줄거리 분량 기준과 코드 위치(미확인, Claude Code 작업 없이 진행하기로 해 조사하지 않음).
- 작품별 원작 분량 정보(글자 수·원고지 매수 등)가 데이터에 있는지. 비례 규칙에 필요.
- 저작권 제약 여부: 보호기간이 지난 작품 위주로 검증 스크립트(validate_digest.js)가 보호 작품을 막는다는 이전 대화 기록에 근거한 추정이며, 확정 아님. 줄거리 분량 자체는 법적 제약이 아닐 가능성이 높으나 일반론이고 법률 자문 아님.

## 위험
- 줄거리가 길고 구조가 세분될수록 AI가 사실을 지어낼 위험이 커짐. 장편은 원작과 대조 가능한 작품부터 진행.
- 단계 구분(특히 절정)은 해석이 들어감. 해석임을 구분해 표시하거나 근거 없는 확정을 피할 것.
- 기존 작품 60편(소설)의 줄거리 재작성 분량이 큼.

## 참고
- 기승전결보다 5단계를 택한 이유: 5단계가 학교 국어의 소설 구성 설명에서 표준적으로 쓰인다는 일반 지식에 근거(교과서 표기 확인은 안 함).
