# 음성 학습 메뉴 (가칭) 설계·진행 현황

기준일: 2026-10-05 (작업 193까지 배포 완료)

## 목적
- 사용자: 가족 (전원 15세 이상). 고등학교 과정 여러 과목을 본인 목소리로 읽어 저장하고 복습.
- 흐름: 읽고 녹음(이어서 녹음 가능) → 글로 변환(원문, 수정 가능) → 구조화 요약 → 요약 듣기 → 퀴즈(오답 노트) / 이어서 대화하기 / 자료 간 연결 / 연상 그림. 자료 합치기 지원.
- 개념 카드는 별도 메뉴 "개념학습"으로 분리 예정(claude/concept-study-design.md 참고).
- 화면 주소: /voice_study.html, 홈 휠 메뉴 "음성 학습"(가칭)에서 연결.

## 확정 결정
- 음성 파일은 서버에 저장하지 않음. 변환 후 폐기. 원문+요약만 DB(voice_notes)에 저장.
- 변환(STT): OpenAI. 모델은 Railway 변수 VOICE_STT_MODEL. 현재 whisper-1로 알고 있으나 변수 값은 재확인 필요(코드 기본값은 gpt-4o-mini-transcribe). gpt-4o 계열은 출력 한도 2,000토큰이 공식 문서에서 확인되어 긴 녹음에 부적합.
- 요약·퀴즈·대화·연결·그림 계획·글자 대조: Claude Haiku 4.5 (claude-haiku-4-5-20251001). 원문에 있는 내용만 사용.
- 읽어주기: 브라우저 내장 음성(비용 0). 품질이 나쁘면 OpenAI TTS로 교체 검토.
- 퀴즈: 4지선다만, 5문제. 문제마다 원문 근거 문장을 서버가 검증. 3문제 미만이면 생성 실패(422).
- 이어서 대화하기: 자료 한 개 안에서만. 원문에 없으면 "자료에 없습니다."로 답. 대화 내용은 저장하지 않음. 한 대화 질문 10개.
- 사용량 상한(사용자당 하루): 변환 20, 요약 30, 퀴즈 10, 대화 60, 연결 30. 자료 최대 200건.
- 권한: users.perm_voice_study (기본 true), 관리자 화면 "음성" 열에서 토글.
- 메뉴 이름: 가칭 "음성 학습" (미확정). 학습 현황 표시 방식: 미결정.

## 구조화 요약 (작업 187)
- 유형 6종: 개념 설명 / 시간·사건 / 원리·절차 / 비교·분류 / 주장·논증 / 용어·어학. 유형별 칸 이름은 서버가 고정, 모델이 유형 자동 선택(사용자 지정 가능).
- 항목마다 원문에서 복사한 근거 구절(8자 이상)을 서버가 검증. 미검증 항목은 "⚠ "를 붙여 유지. 항목 칸당 6개, 전체 20개 상한.
- 과목·세부 과목 지정(국어·영어·수학·과학·사회·역사·기타, 세부 포함).
- 근거 검증은 "구절 존재"만 확인하며 의미 일치는 보증하지 않음.

## 자료 간 연결 (작업 188, 193-1 보강)
- 요약 저장 시 자동(백그라운드, 요약 해시당 1회, 같은 과목만). 후보는 단어 겹침 점수 상위 3개(AI 비용 없음), 원문은 각 앞 8,000자.
- ✔ 근거 확인: 두 원문에 모두 있는 구절(각 10자 이상) 검증 통과. 통과하지 못하면 ◇로 강등.
- ◇ 배경지식 연결과 연상 키워드(최대 8개): 원문 근거 없음, "사실 확인 필요" 표시.
- 193-1: 프롬프트 규칙 8 추가(배경지식 문장에 두 자료에 없는 연도·수치·인명·고유명사 금지). 서버는 숫자만 검사: 두 자료에 없는 숫자가 든 배경지식 연결은 통째로 삭제, 키워드 hint는 해당 hint만 비움. 인명·고유명사는 서버가 검사하지 못하고 프롬프트에만 의존.
- 요약이 바뀌면 오래된 연결은 숨김. 합본-원본 관계는 후보에서 제외(192).

## 연상 그림 (작업 189·189-2·190, 배포됨, 기능 꺼짐 상태)
- 요약 → 장 나누기와 6칸 이내 문구(Haiku, 장 수는 AI가 판단, 상한 VOICE_IMAGE_MAX_PAGES 기본 3) → 장별 이미지(OpenAI) → 장별 글자 대조(Haiku 비전) → 저장(voice_image_sets, voice_images).
- 원칙: 이미지 단순화, 필요한 텍스트·기호 반영, 흐름이 있는 장만 화살표. 문구는 서버가 요약 대조로 검증하고 ⚠ 항목은 제외.
- 글자 대조: 여분 글자 12자 초과 또는 누락이면 fail(1회 재생성). 화면에 ✔/⚠/불가 배지.
- 켜는 변수(기본 꺼짐): VOICE_IMAGE_ENABLED, VOICE_IMAGE_MODEL(gpt-image-2.5-flare), VOICE_IMAGE_QUALITY(medium), VOICE_IMAGE_FORMAT(jpeg), VOICE_IMAGE_COMPRESSION(85), VOICE_IMAGE_DAILY_CAP(4), VOICE_IMAGE_MAX_PAGES(3), VOICE_IMAGE_MAX_BYTES(권장 3500000), VOICE_IMAGE_COST_USD(실측 후 입력).
- 단가: 공식 문서는 토큰 단가만 제시. 장당 단가는 미공시, 실측 필요.
- 시험 결과(앱 외부 시험, 경제 2종·역사 2종): 필수 문구 4건 모두 일치, 지시하지 않은 글자가 4건 중 3건에 추가(1건은 내용 오류). 코드 렌더링(SVG)은 글자 오류가 없으나 연상 효과가 낮아 이미지 생성 방식 채택(사용자는 GPT 스타일 선호).
- 효용(암기 도움)은 미검증. 👍/👎 평가를 자료별로 저장만 하며 집계 화면은 없음.

## 이어서 녹음 (작업 191, 배포됨)
- 첫 변환 성공 시 자동 저장(제목 "음성 자료 M/D HH:mm"), 저장된 자료에서 "이어서 녹음"으로 원문 끝에 이어 붙임(자동 저장). 방금 추가한 조각은 1회 되돌리기.
- 일시정지/재개(지원 브라우저만), 4분 경과 안내, 변환 실패 시 녹음을 유지해 "다시 변환". 글자 수 "n / 한도자" 표시.
- 서버: voice_notes.summary_source_hash, summary_stale(요약 이후 원문이 바뀌면 배너·목록 배지). 기존 자료(해시 없음)는 요약을 다시 저장해야 추적 시작.
- 한계: 동시에 두 기기에서 이어 붙이면 나중 저장이 덮어씀. 요약 자동 갱신은 하지 않음.

## 자료 합치기 (작업 192·192-2, 배포됨)
- 같은 사용자의 자료 2~6개를 순서대로 이어 붙여 새 자료(합본) 생성. 원본은 변경하지 않음. 과목은 모두 같을 때만 상속.
- merged_from에 원본 id·제목·해시 저장. 상세에서 원본 상태(정상/변경됨/삭제됨) 표시, 자동 반영 없음.
- 원문 최대 길이 VOICE_TRANSCRIPT_MAX 기본 30,000자(목록 응답 {notes, limits}).
- 192-2: server.js 전역 JSON 본문 한도 100KB → 1MB. (원문 30,000자 + 요약 5,000자 약 105KB가 이전에 413으로 거절됨, 모의 테스트로 재현·해결.)

## 오답 노트 (작업 193-3, 배포됨)
- 퀴즈 결과를 서버가 채점·저장(voice_quiz_attempts, 문제 스냅샷 포함, 자료당 최근 50개). 화면의 점수·정답은 서버 값.
- 오답 노트: 자료별 묶음, 문제·내가 고른 답·정답·근거. 이후 시도에서 같은 문제를 맞히면 제외, 다시 틀리면 재등록. 최근 500건을 훑어 최대 200개.
- 미구현: 오답만 다시 풀기, 학습 현황 화면.

## 미확인·위험
- 운영 DB: 191·192 새 컬럼(summary_source_hash, merged_from)은 voice_notes 마이그레이션이 오류 없이 끝난 것으로 보이나 컬럼 단위 확인은 안 됨. 목록의 sha256 SQL(PostgreSQL 11 이상 필요)은 목록 화면이 정상으로 뜨는지로 확인. 실패 시 로그에 "voice-notes list stale error".
- 로그인 상태 실제 동작: 이어서 녹음, 합치기, 오답 노트.
- Railway 프록시 본문 한도(앱 한도 1MB), 아이폰 녹음 일시정지·재개, 5분 이상 긴 녹음의 whisper-1 변환.
- 188 연결 품질: 실제 Haiku의 193-1 규칙 준수, 숫자 검사로 정상 문장이 탈락하는 정도. 인명·고유명사 오류는 서버가 못 걸러냄.
- 연상 그림: 한글 글자 정확도, 장당 실제 비용, jpeg 수용, Haiku 비전 정확도, 아이폰 저장. 기능은 아직 켜지 않음.
- 관리자 비용 화면 STT 단가: 193-2로 모델별 코드 단가표(whisper-1 0.006, gpt-4o-transcribe 0.006, mini 0.003) 적용. 표는 OpenAI 공식 가격으로 확인되지 않았고, VOICE_STT_COST_PER_MIN을 설정하면 우선. VOICE_STT_MODEL 실제 값 확인 필요.
- mydict 서비스는 같은 저장소에서 함께 재배포되는 것이 확인됨(배포 성공 표시 기준). 가족 안내: 당분간 3분 이내 조각 녹음 권장.
