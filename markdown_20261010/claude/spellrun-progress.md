## 규칙 요약
- 보스: 한 판 5번째마다(기본 모드는 최대 10단어 중 5·10번째). 긴 단어 우선 배정. 복습 판에는 없음.
- 속도: 콤보 2부터 25%씩 올라 콤보 5에서 최고 속도(169~364).
- 2단 점프: 기본 켜짐, 높은 칸은 2단 점프로만 획득(+100).
- 장애물(326·327): 묶음 사이 간격에 단어당 최대 1개(확률 0.5). 맞으면 체력 -1, 속도 ×0.6, 0.8초 무적. 판정 크기 28×28(구덩이 36) 불변.
- 하트: 체력과 무관하게 나옴. 가득일 때 먹으면 +100(hpfullbonus).
- 번개(가속): 일반 단어 4개 그룹마다 1개. 하트·장애물·구조 단어면 같은 그룹 안에서 시작 후보부터 앞으로 이동(339). 효과 5초, 목표 속도 ×1.3(최고 속도 한도 안), 단어 완성 점수 ×1.5, 장애물 맞으면 종료.
- 구조 아이템(힌트 전구·천사): 체력 ≤ 최대의 60%(기본 3 이하)에서 단어당 1/2, 체력이 더 높아도 약 1/5(340). 힌트/천사 구분은 단어 해시. 우선순위 하트 > 구조 > 번개. 난수 없이 해시 기반.
- 생존 모드(332): 시작 화면 모드 버튼(기본/생존, 별도 저장 키 spellrun_mode), 5단어 이상, 5번째마다 보스, 하트는 간격이 점점 늘어남, 장애물 확률이 10단어마다 소폭 상승. 결과: 푼 단어, 점수, 최대 콤보, 생존 시간, 틀린 단어.
- 이어하기(341): 체력 0이 되면 "이어하기/끝내기". 판당 1회, 체력 절반(올림), 점수·콤보 유지, 방금 단어 처음부터, 직후 1.5초 피격 무시. 생존 시간은 선택 화면 시간 제외. 결과에 사용 여부 표시. continue=0|1.
- 시작 전 미리 보기(345): 단어 목록을 자동으로 순서대로 재생. 351에서 bfcache 복귀(뒤로 갔다 돌아옴) 때 어긋나지 않게 처리. 시작 화면(346)은 핵심 요약 + "게임 방법" 펼치기.
- 화면 구조(355): layoutFor(mode, screen). 세로는 W=360, 높이 가변(남는 높이는 하늘 2/3·땅 아래 1/3, 높이 640에서 옛 520/412/305와 동일), 가로는 800x400. 세로 동일성은 tests/fixtures/spellrun_classic_trace.json과 354-3·355-3 시험이 지킴.
- 가로 규칙(354~357): 타일·장애물·아이템은 항상 오른쪽 끝에서 들어옴. 다음 단어 타일이 미리 보임. 틀린 철자를 먹으면 화면 밖 타일만 다시 계획하고 화면 안 타일은 그대로, 필요한 철자는 나중에 오른쪽 끝에서 다시 들어옴(길게 기다리는 것 수용). 첫 타일이 맞으면 남은 타일은 흘려보내고 다음 묶음을 늦춤(+0.84초 최소 속도). 자동 회전·방향 잠금 없음: 가로를 골랐는데 폰이 세로면 위쪽 안내 띠만 표시하고 게임은 멈추지 않음(혼자·대결 동일). Android는 탭 안에서 requestFullscreen, iPhone은 홈 화면 앱 + viewport-fit=cover/safe-area(iPhone 홈 화면 앱 로그인·전체 화면은 아직 폰 확인 전).
- 가로 360~362: 캐릭터 그림 1.3배(판정 크기 불변), 타일 폭 58→43.5, MIN_GAP 90→67.5, PAD 32→24, 흐림 삭제. 상단은 하트·점수·[메뉴](계속하기·소리·세로로·닫기, 혼자는 열면 멈춤, 대결은 멈추지 않음), 콤보 칩 숨김. 타일은 풍선(몸통 48x52 논리 px, 6색을 (후보 번호+칸 번호)%6으로 배정, 난수 없음). 풍선은 위아래 ±3px 주기 1.6초, 매듭 축 ±4도 흔들림. 풍선 그림 위치만 22px 올림(TILE_LIFT, 먹는 판정 GRAB_H 22·HIGH_GRAB_H 160 불변). 맞는 풍선은 터지며 같은 색 조각 7개. 틀린 풍선과 "틀리기 전에는 계획의 정답이었지만 지금은 아닌" 풍선은 약 0.9초 가속하며 위로 올라가 사라짐(투명해지지 않음, 먹는 판정 제외, 점수·콤보·체력 영향 없음). 처음부터 오답 후보였던 풍선과 지금 필요한 정답은 그대로 지나감. 정답을 놓쳐서 다시 계획할 때도 같은 규칙으로 쓸모없어진 풍선이 올라감(363).
- 캐릭터 동작 효과(363, 가로만): 점프 시작 0.1초 세로 1.12/가로 0.92, 착지 0.12초 세로 0.85/가로 1.12에서 복귀(발끝 고정), 달릴 때 ±1.95px 출렁임, 점프 높이에 따라 작아지고 연해지는 그림자, 먼지(착지 3개, 달릴 때 0.2초마다 1개, 총 24개 이하), 맞으면 폴짝 + 별 4개, 틀리면 기울어짐과 좌우 흔들림(투명해지지 않음). 틀렸을 때의 화면 전체 흔들림과 장애물에 맞았을 때 캐릭터 깜박임은 가로에서 뺌. 반응 상태 G.react {kind, t0, dur}: happy 0.4초 / hurt 0.5초 / surprise 0.3초, 우선순위 hurt > surprise > happy, 게임 시간 기준(메뉴로 멈추면 만료되지 않음).
- 캐릭터 시트(364): 여학생·남학생 시트는 14칸 한 줄 4032x288(달리기 8칸 0~7, 점프 상승 8, 점프 하강 9, 표정 10 기본·11 기쁨·12 아야·13 놀람). 점프 2칸은 358과 바이트까지 같음. 펭귄은 6칸 1728x288 그대로(달리기 4, 점프 상승 4, 점프 하강 5). 표정 프레임은 가로 효과의 반응 상태이고 땅 위일 때만 사용(세로·펭귄은 사용 안 함). 달리기 프레임 길이는 0.11초 × (최저 속도/현재 속도), 4동작 캐릭터는 0.06~0.14초 제한, 8동작 캐릭터는 0.055초(0.03~0.07 제한)라서 한 바퀴 시간이 같음. 대기 프레임은 달리기 1번(서 있는 자세 아님), 완주 기쁨은 점프 상승 칸.

- /api/ai: 로그인 필수, can_search, 하루 200회(AI_DAILY_CAP, 추정값), 입력 검증.
- 호출처(사전 발음, 미리 받기, 팟캐스트, 스펠링 런)는 모두 토큰을 보냄. 오류 시: 사전·스펠링 런은 기기 음성 대체, 팟캐스트는 해당 구간 건너뜀(352에서 팟캐스트 안내 정리).
- 352에서 처리: 기본 비밀값 점검(DATABASE_URL이 있으면 시크릿 점검), 전역 오류 처리기, 로그아웃 경로, 같은 사이트 CORS(lib/http_safety.js). 옛 회귀 시험은 가짜 시크릿(test-only-secret)이 필요해서 358-1에서 보정.
- DELETE /api/tts/cache는 관리자 전용(화면에서 쓰지 않으므로 나중에 제거 후보).
- 알려진 위험: 하루 AI 한도 200회는 단어장 뜻 요약 백필이 많으면 넘을 수 있고, 넘으면 대체값을 조용히 사용.

## 2인 대결 (구현 완료: 343·344·347·348·349·350)
