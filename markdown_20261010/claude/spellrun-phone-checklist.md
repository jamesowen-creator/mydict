# 스펠링 런·대결 폰 확인 목록

폰에서만 확인할 수 있는 것을 한꺼번에 보기 위한 목록이다. 항목마다 "어디서 / 무엇을 / 기대 동작" 한 줄이다.
작성: 작업349 (기준 커밋 af1ca7e, sw.js metis-v75). 컴퓨터의 헤드리스 시험이 이미 확인한 것은 넣지 않았다. 폰에서만 의미 있는 것만 적었다.
"흉내(추정)"라고 적힌 것은 컴퓨터에서 브라우저로 흉내 낸 결과이고, 실제 폰은 다를 수 있다.

## 0. 시작 전

- [ ] 폰에서 앱을 한 번 완전히 닫았다 연다. 설정에서 홈 화면 앱이면 삭제 후 다시 설치하지 않아도 되지만, 화면 상단 주소가 `/spelling_run.html` 인 상태에서 새로고침을 한 번 한다. 기대: 옛 화면이 아니라 v75 가 뜬다(서비스 워커 캐시 갱신). 안 바뀌면 사이트 데이터 삭제 후 다시 연다.

## 1. 스펠링 런 혼자

- [ ] 스펠링 런 시작 화면 / 문구를 읽는다 / 모드 설명이 한 줄이고 핵심 요약이 3줄이다 (346)
- [ ] 스펠링 런 시작 화면 / 스크롤하지 않고 화면을 본다 / "달리기 시작" 버튼이 스크롤 없이 보인다 (346)
- [ ] 시작 화면 / "게임 방법"을 누른다 / 상세 규칙이 열리고, 다시 누르거나 닫기를 누르면 닫힌다. 모드·미리 보기 설정은 바뀌지 않는다 (346)
- [ ] 게임 방법 안 / "소리 켬"과 "발음 테스트"를 누른다 / 소리 설정이 바뀌고, 발음이 나오거나 기기 음성으로 대체된다는 안내가 나온다 (346)
- [ ] 한 판 달리기 / 번개 아이템이 나오는 빈도를 본다 / 한 판(생존 모드 몇 분)에서 번개가 가끔 보이고, 한 묶음에 두 개가 나오거나 한 번도 안 나오지는 않는다 (339)
- [ ] 한 판 달리기 / 체력이 가득 찬 상태에서 힌트(전구)·천사가 나오는지 본다 / 체력이 높아도 가끔(단어 5개에 한 번 정도) 나온다. 체력이 낮을 때는 더 자주 나온다 (339, 340)
- [ ] 한 판 달리기 / 일부러 체력을 0으로 만든다 / 게임이 멈추고 "이어하기 / 끝내기" 선택이 뜨며, 이어하기를 누르면 체력이 절반으로 돌아와 같은 단어를 처음부터 하고, 직후 약 1.5초는 장애물에 맞아도 체력이 줄지 않는다 (341)
- [ ] 이어하기 선택 화면 / 한참(10초 이상) 둔다 / 그 시간은 생존 시간에 들어가지 않는다(결과 화면 시간이 그만큼 길어지지 않는다) (341)
- [ ] 이어하기를 이미 쓴 판 / 체력을 다시 0으로 만든다 / 선택 없이 바로 끝난다 (341)
- [ ] 주소 뒤에 `?ttsdebug=1` 을 붙여 연다 / 발음 테스트를 누른다 / 발음 출처(서버 음성 HIT/MISS 또는 기기 음성 사유)가 화면 한쪽과 테스트 결과에 보인다. 붙이지 않으면 아무 표시가 없다 (325)

## 2. 발음·검색

- [ ] 사전 / 단어를 검색하고 발음 버튼을 누른다 / 소리가 난다. 서버 음성이 안 되면 기기 음성으로 나온다 (335, 337)
- [ ] 사전 / 같은 단어 발음을 두 번째 눌러 본다 / 두 번째가 더 빠르다(캐시). 소리 없이 조용히 실패하지 않는다 (337)
- [ ] 사전 / AI 검색(뜻 확인, 예문 생성)을 한다 / 정상으로 답이 나온다. 로그아웃 상태에서는 로그인 안내가 나온다 (338)

## 3. 대결 혼자 (가족 권한을 켜기 전에, 본인 관리자 계정으로)

- [ ] 스펠링 런 시작 화면 / 모드에 "대결"이 보이는지 본다 / 관리자 계정에는 보인다. 권한이 없는 계정에는 보이지 않는다 (344)
- [ ] 대결 / "방 만들기" 후 "먼저 달리기"를 누른다 / 게임이 시작되고 아래쪽에 상대 막대(상대를 기다리는 중)가 있다. 막대가 글자·HUD를 가리지 않고 한 줄에 들어간다 (347)
- [ ] 대결 중 / 오른쪽 아래 "나가기"를 본다 / 막대 바로 위 오른쪽 끝에 있고, 점프하려고 화면을 탭할 때 잘못 눌리지 않는다. 엄지로 오른쪽 아래 근처를 연달아 탭해 보면 확인창이 뜨는 일이 없어야 한다 (348)
- [ ] 대결 중 / "나가기"를 눌러 확인창을 연다 / "나가면 지금 기록으로 종료돼요. 나갈까요?"가 뜨고, 열려 있는 동안 펭귄이 멈춘다. "계속 달리기"를 누르면 이어서 달린다 (348)
- [ ] 확인창에서 "나가기"를 누른다 / 방 목록으로 돌아간다 (348)
- [ ] 혼자 먼저 달리다 체력 0 → 이어하기 / 끝내기 / 끝내면 "상대 없이 끝났어요"가 나오고 "방 목록으로"가 보인다 (347)
- [ ] 대결 중 / 화면 위쪽 글자(뜻)와 아래 상대 막대가 겹치지 않는지 본다 / 폰의 실제 화면 비율에서도 겹치지 않는다 (347)

## 4. 대결 두 사람 (가족 한 명의 대결 권한을 켠 뒤)

권한 켜는 방법은 맨 아래 "5. 가족 한 명에게 대결 권한 켜기"를 따른다.

- [ ] 방장 폰 + 참가자 폰 / 방장이 방을 만들고 참가자가 목록에서 참가한다 / 참가자 목록에 방이 보이고, 참가하면 두 화면 모두 "두 사람이 모였어요"가 된다 (344)
- [ ] 두 폰 / 각자 시작을 눌러 달린다 / 서로의 이름·체력·점수·콤보·단어 번호가 아래 막대에 1~2초 안에 갱신된다 (347)
- [ ] 두 폰 / 각자 끝낸다 / 두 화면의 승·패·무와 이유 문구가 서로 맞는다(한쪽 승리면 다른 쪽 패배) (347)
- [ ] 두 폰 / 결과에서 양쪽이 "다시 하기"를 누른다 / 두 화면 모두 준비 화면으로 가고, 다시 달려 결과가 나온다. 두 번째 판의 단어 순서는 첫 판과 다르다 (348)
- [ ] 두 폰 / 한쪽이 먼저 "다시 하기"를 누른다 / 누른 쪽은 "상대의 다시 하기를 기다리는 중", 상대 쪽은 "상대가 다시 하기를 원해요"가 보인다 (348)
- [ ] 두 폰 / 한쪽이 결과 화면에서 "방 목록으로"를 누른다 / 남은 쪽에 "상대가 방을 나가서 다시 할 수 없어요"가 나오고 다시 하기 버튼이 없다 (348)
- [ ] 두 폰 / 달리는 중 한쪽이 "나가기"로 나간다 / 남은 쪽 막대에 "나감"이 보이고, 끝난 뒤 결과에 "상대가 중간에 나갔어요"가 보인다 (348)
- [ ] 두 폰 / 방장이 먼저 달리는 중에 다른 폰이 참가해 시작한다 / 방장 화면에 "상대가 들어왔어요"가 한 번만 나오고 막대에 상대 이름이 나온다 (347)
- [ ] 앱 전환 10초 / 달리는 중 홈 버튼으로 다른 앱을 10초 열었다가 돌아온다 / 돌아오면 같은 방에 남아 계속 달린다. 상대 화면에 "나감"이 뜨면 안 된다. 흉내(추정): 숨김만으로 leave 는 나가지 않고 복귀 즉시 신호를 보낸다 (349)
- [ ] 앱 전환 40초 이상 / 달리는 중 다른 앱을 40초 이상 쓰다가 돌아온다 / 상대 화면에 "연결 끊김"이 뜨고, 돌아온 쪽은 "연결이 끊겨 종료됐어요"와 마지막 점수·푼 단어 수가 보인다. 흉내(추정): 약 30초에 서버가 끊김 처리 (349)
- [ ] 화면 잠금 / 달리는 중 전원 버튼으로 화면을 껐다가 15초 뒤 켠다 / 앱 전환 10초와 같이 방에 남는다(30초를 넘기면 끊김). 폰·브라우저에 따라 다를 수 있다 (349)
- [ ] 화면 회전 / 대결 중 폰을 가로로 눌렀다 세로로 돌린다 / 게임이 멈추거나 방에서 나가지 않고, 상대 막대·나가기 버튼이 화면 안에 그대로 보인다 (349)
- [ ] 브라우저 닫기 / 달리는 중 탭을 닫거나 앱을 스와이프로 종료한다 / 상대 화면에 몇 초~30초 안에 "나감" 또는 "연결 끊김"이 뜬다. 흉내(추정): 닫힘(pagehide persisted=false)은 leave 가 나간다 (349)
- [ ] 뒤로 가기·앞으로 가기 / 대결 중 브라우저 뒤로 가기로 나갔다가 앞으로 가기로 돌아온다 / 알려진 문제 B1: 지금은 돌아온 사람이 방에서 빠진 상태로 보인다(350에서 수정 예정). 수정 후에는 방에 남아 있어야 한다 (349)
- [ ] 모바일 데이터와 Wi-Fi / 달리다가 Wi-Fi를 끄고 데이터로 전환한다 / 몇 초 끊겨도 게임이 멈추지 않고 이어서 신호가 간다(연결이 짧게 끊긴 뒤 복구). 30초를 넘기면 끊김 처리된다 (349)
- [ ] 데이터 사용량 / 한 판(1~2분) 뒤 설정에서 데이터 사용량을 본다 / 눈에 띄게 크지 않다. 시험에서 사람당 평균 초당 약 1.5건, 최대 초당 3건(요청이 작다) (349)
- [ ] 배터리·발열 / 10분 정도 연속으로 두 판 이상 한다 / 평소 스펠링 런 혼자 할 때와 체감 차이가 크지 않다 (349)
- [ ] 서버 재시작 / (배포 직후 등) 대결 중 서버가 다시 시작되면 / 게임 중이면 끝까지 달리고 "방 연결이 끊겨 기록은 남지 않아요"가 한 번 뜨며, 끝나면 "방이 사라져 결과를 겨루지 못했어요"와 내 기록, "방 목록으로"가 나온다. 배포 직후에 우연히 겹치면 확인한다 (348)
- [ ] 두 폰 동시에 "다시 하기" / 두 사람이 거의 같은 순간에 누른다 / 새 판이 한 번만 열린다(두 번째 판 번호가 3이 되지 않는다) (349)
- [ ] 알림 / 대결 중 전화나 알림 팝업이 와서 화면을 가렸다가 돌아온다 / 앱 전환 10초와 같이 방에 남는다 (349)

## 5. 가족 한 명에게 대결 권한 켜기 (관리자 화면 코드를 읽고 정리, 작업349)

근거: public/admin.html 의 사용자 관리 표, routes/admin.js 의 PATCH `/api/admin/users/:id` (perm_versus 불리언), routes/versus.js 의 권한 확인(관리자 또는 perm_versus).

1. 켜려는 가족이 먼저 앱에 한 번 Google 로그인한 적이 있어야 한다(사용자 목록에 있어야 한다). 목록에 없으면 그 가족에게 앱에 로그인해 달라고 부탁한다.
2. 관리자 계정으로 로그인한다. 앱 상단 헤더에 "관리자" 버튼이 보인다(관리자 계정에만 보임). 누르면 `/admin` 관리자 화면이 열린다.
3. 관리자 화면에서 "사용자 관리" 표(새로고침 버튼 있음)를 찾는다. 열 이름: 사용자, 역할, 승인, 차단, 언어 사전, 문학 나침반, 한입 독서, 과학, 음성 학습, 개념 지도, 문장 학습, 대결, 검색 횟수, TTS 횟수, 단어장, 저장.
4. 가족의 행을 찾아 "대결" 열의 토글을 켠다(처음에는 꺼져 있다. 다른 권한 토글처럼 기본이 켜짐이 아니다). 같은 행의 승인은 켜져 있고 차단은 꺼져 있어야 한다.
5. 같은 행 맨 오른쪽 "저장" 버튼을 누른다(토글을 바꾸면 그때 활성화된다). "저장되었습니다." 안내가 뜬다. 저장 전에는 서버에 반영되지 않는다.
6. 가족에게 스펠링 런을 새로 열어(또는 새로고침) 모드 줄에 "대결"이 생겼는지 확인해 달라고 한다. 권한이 없으면 버튼이 안 보인다.
7. 대결 권한은 단어장 권한과 별개다. 가족이 대결을 하려면 단어장에 영어 단어가 10개 이상 있어야 한다(방 만들기·참가가 막힌다).
8. 끄려면 같은 토글을 끄고 저장한다. 끈 직후 대결 중이던 사람은 다음 요청에서 "대결 사용 권한이 없어요"가 뜨고 메뉴가 사라진다.
