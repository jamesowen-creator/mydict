# 스펠링 런·대결 폰 확인 목록

폰에서만 확인할 수 있는 것을 한 번에 보기 위한 목록이다. 항목마다 "어디서 / 무엇을 / 기대 동작" 한 줄이다. 괄호 숫자는 관련 작업 번호다.
작성: 작업349, 작업357에서 순서를 정리하고 컴퓨터 시험이 이미 확인한 항목을 뺐다(sw.js metis-v83). "흉내(추정)"라고 적힌 것은 컴퓨터에서 브라우저로 흉내 낸 결과이고 실제 폰은 다를 수 있다.

## 준비 사항 (먼저 3가지)

1. 앱을 완전히 닫았다가 다시 연다(새 버전을 받기 위해). 스펠링 런 화면에서 새로고침을 한 번 하고, 안 바뀌면 사이트 데이터를 지우고 다시 연다.
2. iPhone은 Safari 탭이 아니라 홈 화면에 추가한 앱으로 연다(주소창이 없는 화면). 예전에 추가한 아이콘은 지우고 다시 추가해야 반영될 수 있다.
3. 폰의 자동 회전을 켠다(가로 확인에 필요하다).

## 1. 혼자 하기 (세로)

- [ ] 시작 화면 / "달리기 시작" 버튼과 [닫기]·[가로로]를 본다 / 스크롤 없이 모두 보이고, 주소창·앱 헤더가 없이 판이 화면을 꽉 채운다 (355)
- [ ] 큰 폰(세로 400x900 이상) / 한 판 달린다 / 판이 화면 전체를 채우고 위 하늘이 더 넓어 보인다. 뜻·글자 칸·타일 글자가 작은 폰과 같거나 크고, 땅·타일·점프 높이는 같은 느낌이다 (355)
- [ ] 한 판 / 단어 미리 보기를 켠 채 시작해 도중에 다른 앱을 열었다 돌아온다 / 미리 보기가 끝나지 않고 같은 단어부터 이어진다. 직접 일시정지했으면 멈춘 채다 (351)
- [ ] 한 판 / 번개·힌트(전구)·천사 아이템이 나오는 빈도를 본다 / 번개가 가끔 보이고 한 묶음에 두 개가 나오지 않는다. 체력이 낮으면 힌트·천사가 더 자주 나온다 (339, 340)
- [ ] 한 판 / 체력을 0으로 만든다 / "이어하기 / 끝내기" 선택이 뜨고, 이어하기를 누르면 체력이 절반으로 돌아와 같은 단어를 처음부터 한다 (341)
- [ ] 시작 화면 / "게임 방법"을 열고 "소리 켬"·"발음 테스트"를 누른다 / 소리가 나오거나 기기 음성으로 대체된다는 안내가 나온다 (346)
- [ ] [닫기] / 시작 화면과 달리는 중에 누른다 / 단어장으로 돌아간다. 전체 화면이면 함께 꺼진다 (355)

- [ ] Android Chrome / 전체 화면에서 뒤로 가기 제스처로 전체 화면을 끈다 / 게임은 멈추지 않고 계속되며 전체 화면을 다시 요청하지 않는다 (355)
- [ ] iPhone 홈 화면 앱 / 가로로 돌려 왼쪽·오른쪽 노치 쪽과 아래 홈 표시줄 쪽을 본다 / 하트·점수·단추가 노치·홈 표시줄에 가리지 않고, 여백은 어두운 배경으로 화면 끝까지 채워진다(하얀 줄 없음) (355)

- [ ] 가로 뜻·글자 칸 / 한 판 달린다 / 왼쪽에 뜻, 오른쪽에 글자 칸이 한 줄이고 위 한 줄(체력·진행·속도 | [닫기][세로로] | 콤보·점수·소리)과 겹치지 않는다. 글자가 읽기 편하다(844x390 기준 뜻 약 25px, 글자 칸 약 37px). 긴 뜻은 두 줄로 줄어든다 (356)
- [ ] 가로 흐름 / 가로로 한 판 한다 / 타일·장애물·아이템이 항상 오른쪽 끝에서 들어오고 화면 중간에 갑자기 생기지 않는다. 지금 풀 묶음만 진하고 남은 타일·다음 묶음은 흐리다. 틀린 뒤 맞는 글자가 다시 오기까지 기다림(폭 800, 최저 속도 약 4.5초)이 답답한지 느낌을 적는다 (354, 355)

- [ ] 가로 카드 / 시작·결과·미리 보기·이어하기 화면을 연다 / 2열로 한 화면에 들어오고 주 버튼(달리기 시작, 새 판 시작 등)이 스크롤 없이 보인다 (356)
- [ ] 새 배경 / 한 판 달린다(세로·가로 모두) / 낮에는 연한 언덕·풍차와 꽃핀 초록 언덕·울타리, 구름이 천천히 흐르고 위쪽 뜻·글자 칸 뒤는 깨끗한 하늘이다. 보스 단어에서는 별이 있는 석양 하늘과 보라 능선으로 약 0.5초 동안 부드럽게 바뀌고, 위쪽 글자가 흰색으로 읽힌다. 보스가 끝나면 낮으로 돌아온다 (358)
- [ ] 새 장애물 / 장애물이 나오는 판을 한다 / 이끼 돌무더기·버섯 통나무·별 상자·가시덤불 4종이 나오고, 가시덤불이 배경 덤불(초록 언덕의 덤불)과 헷갈리지 않는다. 장애물이 가로로 넓어 보여도 넘는 느낌이 자연스럽다 (358)
- [ ] 캐릭터 선택 / 시작 화면에서 "캐릭터: 펭귄 | 여학생 | 남학생"을 고른다 / 작은 그림과 이름이 보이고(터치 편함), 고른 캐릭터로 달린다. 다음에 열어도 마지막 선택이 남는다. 달리기·점프·2단 점프 회전·넘어짐이 자연스럽고 화풍이 어색하지 않다 (358)
- [ ] 프레임 끊김 / 새 배경과 캐릭터로 한 판 달린다(가로·큰 화면 포함) / 이전보다 눈에 띄게 끊기지 않는다. 느리면 어떤 폰에서 어떤 화면(세로·가로)인지 적는다 (358)
- [ ] 아이템 그림 / 하트·번개·힌트 전구·천사 아이템이 나오는 판을 한다 / 번개(노랑)와 전구(노랑)가 달리면서 구분된다(번개는 쪼개진 모양, 전구는 둥근 유리와 은색 소켓). 구분이 어려우면 적는다. 먹었을 때 효과와 연출은 이전과 같다 (358)
- [ ] 회전 안내 띠 / 가로를 골라 두고 폰을 세로로 든다 / 맨 위에 "폰을 가로로 돌려 주세요(폰의 자동 회전이 켜져 있어야 해요)"와 [세로로 하기]가 보이고 게임은 멈추지 않는다. 폰을 가로로 돌리면 띠가 사라진다 (355)
- [ ] [가로로]·[세로로] / 달리는 중 눌러 본다 / "판이 끝나면 …로 바뀌어요"가 뜨고 판 크기는 그대로, 판이 끝나면 바뀐다. 시작 화면에서는 곧바로 바뀐다 (355)

## 3. 대결 혼자 (가족 권한을 켜기 전에, 본인 관리자 계정으로)

- [ ] 시작 화면 / 모드 줄에 "대결"이 보이는지 본다 / 관리자 계정에는 보이고, 권한이 없는 계정에는 보이지 않는다 (344)
- [ ] 대결 / "방 만들기" 후 "먼저 달리기"를 누른다 / 게임이 시작되고 아래쪽에 상대 막대(상대를 기다리는 중)가 있다. 막대가 글자·HUD를 가리지 않는다 (347)
- [ ] 대결 중 / "나가기"를 본다(세로는 막대 위 오른쪽 끝, 가로는 아래 오른쪽 끝) / 엄지로 화면을 연달아 탭해도 확인창이 잘못 뜨지 않는다 (348)
- [ ] 대결 중 / "나가기"를 눌러 확인창을 연다 / "나가면 지금 기록으로 종료돼요. 나갈까요?"가 뜨고 열려 있는 동안 펭귄이 멈춘다. "계속 달리기"로 이어가고, "나가기"를 누르면 방 목록으로 돌아간다 (348)
- [ ] 대결 중 / 위쪽 [닫기]를 누른다 / 바로 나가지 않고 같은 나가기 확인창이 먼저 뜬다 (355)
- [ ] 혼자 먼저 달리다 체력 0 / 이어하기 또는 끝내기 / 끝내면 "상대 없이 끝났어요"가 나오고 "방 목록으로"가 보인다 (347)
- [ ] 가로 대결 / 가로로 방 목록·대기·결과 화면을 연다 / 2열로 한 화면에 들어오고 주 버튼이 스크롤 없이 보인다. 방 목록만 영역 안에서 스크롤된다. 대결 막대·나가기가 아래쪽에서 홈 표시줄에 가리지 않는다 (356)

## 4. 대결 두 사람 (가족 한 명의 대결 권한을 켠 뒤)

권한 켜는 방법은 맨 아래 "부록. 가족 한 명에게 대결 권한 켜기"를 따른다.

- [ ] 방장 폰 + 참가자 폰 / 방장이 방을 만들고 참가자가 목록에서 참가한다 / 참가자 목록에 방이 보이고 참가하면 두 화면 모두 "두 사람이 모였어요"가 된다 (344)
- [ ] 두 폰 / 각자 시작을 눌러 달린다 / 서로의 이름·체력·점수·콤보·단어 번호가 아래 막대에 1~2초 안에 갱신된다 (347)
- [ ] 두 폰 / 방장이 먼저 달리는 중에 다른 폰이 참가해 시작한다 / 방장 화면에 "상대가 들어왔어요"가 한 번만 나오고 막대에 상대 이름이 나온다 (347)
- [ ] 두 폰 / 각자 끝낸다 / 두 화면의 승·패·무와 이유 문구가 서로 맞는다 (347)
- [ ] 두 폰 / 결과에서 양쪽이 "다시 하기"를 누른다 / 두 화면 모두 준비 화면으로 가고 다시 달려 결과가 나온다. 두 번째 판 단어 순서는 첫 판과 다르다 (348)
- [ ] 두 폰 / 한쪽이 먼저 "다시 하기"를 누른다 / 누른 쪽은 "상대의 다시 하기를 기다리는 중", 상대 쪽은 "상대가 다시 하기를 원해요"가 보인다 (348)
- [ ] 두 폰 동시에 "다시 하기" / 두 사람이 거의 같은 순간에 누른다 / 새 판이 한 번만 열린다(두 번째 판 번호가 3이 되지 않는다) (349)
- [ ] 두 폰 / 한쪽이 결과 화면에서 "방 목록으로"를 누른다 / 남은 쪽에 "상대가 방을 나가서 다시 할 수 없어요"가 나오고 다시 하기 버튼이 없다 (348)
- [ ] 두 폰 / 달리는 중 한쪽이 "나가기"로 나간다 / 남은 쪽 막대에 "나감"이 보이고 끝난 뒤 결과에 "상대가 중간에 나갔어요"가 보인다 (348)
- [ ] 앱 전환 10초 / 달리는 중 다른 앱을 10초 열었다가 돌아온다 / 같은 방에서 계속 달리고 상대 화면에 "나감"이 뜨지 않는다 (349)
- [ ] 앱 전환 40초 이상 / 달리는 중 다른 앱을 40초 이상 쓰다가 돌아온다 / 상대 화면에 "연결 끊김"이 뜨고 돌아온 쪽은 "연결이 끊겨 종료됐어요"와 마지막 점수·푼 단어 수가 보인다. 흉내(추정): 약 30초에 서버가 끊김 처리 (349)
- [ ] 화면 잠금 / 달리는 중 전원 버튼으로 화면을 껐다가 15초 뒤 켠다 / 앱 전환 10초와 같이 방에 남는다(30초를 넘기면 끊김) (349)
- [ ] 화면 회전 / 대결 중 폰을 세로·가로로 돌린다 / 게임이 멈추거나 방에서 나가지 않고 막대·나가기가 화면 안에 보인다. 가로 선택에서 세로로 들면 안내 띠가 뜨지만 게임은 계속된다 (349, 355)
- [ ] 브라우저 닫기 / 달리는 중 탭을 닫거나 앱을 스와이프로 종료한다 / 상대 화면에 몇 초~30초 안에 "나감" 또는 "연결 끊김"이 뜬다 (349)
- [ ] 뒤로 가기·앞으로 가기 / 대결 중 브라우저 뒤로 가기로 나갔다가 앞으로 가기로 돌아온다 / 돌아오면 같은 방에서 계속 달리고(또는 결과 대기·방 화면이 이어지고) 상대 화면에 "나감"이 뜨지 않는다. 오래 안 돌아오면 30초 뒤 끊김 처리된다 (350)
- [ ] 모바일 데이터와 Wi-Fi / 달리다가 Wi-Fi를 끄고 데이터로 전환한다 / 몇 초 끊겨도 게임이 멈추지 않고 이어서 신호가 간다. 30초를 넘기면 끊김 처리된다 (349)
- [ ] 알림 / 대결 중 전화나 알림 팝업이 와서 화면을 가렸다가 돌아온다 / 앱 전환 10초와 같이 방에 남는다 (349)
- [ ] 서버 재시작 / (배포 직후 등) 대결 중 서버가 다시 시작되면 / 게임 중이면 끝까지 달리고 "방 연결이 끊겨 기록은 남지 않아요"가 한 번 뜨며, 끝나면 "방이 사라져 결과를 겨루지 못했어요"와 내 기록, "방 목록으로"가 나온다. 배포 직후에 우연히 겹치면 확인한다 (348)
- [ ] 데이터 사용량·배터리 / 한 판(1~2분) 뒤 데이터 사용량을 보고, 10분 정도 두 판 이상 한다 / 눈에 띄게 크지 않고 발열·배터리 체감이 혼자 할 때와 크게 다르지 않다. 시험에서 사람당 평균 초당 약 1.5건 (349)

## 5. 발음·검색

- [ ] 사전 / 단어를 검색하고 발음 버튼을 누른다 / 소리가 난다. 서버 음성이 안 되면 기기 음성으로 나온다 (335, 337)
- [ ] 사전 / 같은 단어 발음을 두 번째 눌러 본다 / 두 번째가 더 빠르다(캐시). 소리 없이 조용히 실패하지 않는다 (337)

## 부록. 가족 한 명에게 대결 권한 켜기 (관리자 화면 코드를 읽고 정리, 작업349)

근거: public/admin.html 의 사용자 관리 표, routes/admin.js 의 PATCH `/api/admin/users/:id` (perm_versus 불리언), routes/versus.js 의 권한 확인(관리자 또는 perm_versus).

1. 켜려는 가족이 먼저 앱에 한 번 Google 로그인한 적이 있어야 한다(사용자 목록에 있어야 한다). 목록에 없으면 그 가족에게 앱에 로그인해 달라고 부탁한다.
2. 관리자 계정으로 로그인한다. 앱 상단 헤더에 "관리자" 버튼이 보인다(관리자 계정에만 보임). 누르면 `/admin` 관리자 화면이 열린다.
3. 관리자 화면에서 "사용자 관리" 표(새로고침 버튼 있음)를 찾는다. 열 이름: 사용자, 역할, 승인, 차단, 언어 사전, 문학 나침반, 한입 독서, 과학, 음성 학습, 개념 지도, 문장 학습, 대결, 검색 횟수, TTS 횟수, 단어장, 저장.
4. 가족의 행을 찾아 "대결" 열의 토글을 켠다(처음에는 꺼져 있다. 다른 권한 토글처럼 기본이 켜짐이 아니다). 같은 행의 승인은 켜져 있고 차단은 꺼져 있어야 한다.
5. 같은 행 맨 오른쪽 "저장" 버튼을 누른다(토글을 바꾸면 그때 활성화된다). "저장되었습니다." 안내가 뜬다. 저장 전에는 서버에 반영되지 않는다.
6. 가족에게 스펠링 런을 새로 열어(또는 새로고침) 모드 줄에 "대결"이 생겼는지 확인해 달라고 한다. 권한이 없으면 버튼이 안 보인다.
7. 대결 권한은 단어장 권한과 별개다. 가족이 대결을 하려면 단어장에 영어 단어가 10개 이상 있어야 한다(방 만들기·참가가 막힌다).
8. 끄려면 같은 토글을 끄고 저장한다. 끈 직후 대결 중이던 사람은 다음 요청에서 "대결 사용 권한이 없어요"가 뜨고 메뉴가 사라진다.
