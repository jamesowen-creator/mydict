# 개념학습 (별도 메뉴) 설계·진행 현황

기준일: 2026-10-07. 상태: 작업 194(서버)·195(화면·홈 메뉴·관리자 열) 운영 확인 완료(사용자 확인, 문제 없음). 작업 196(음성 학습에서 개념 제거, 194 이후 개념 재이전) 배포 완료(origin/master = 9b612b8287c35dd46d7c6cadf22232b6d1e6d62f), 사용자가 운영 확인 "정상"으로 보고(세부 확인 범위는 말하지 않음). 이전 방향(직접 입력 카드 + 자동 연결)은 이 문서의 방향으로 대체됨.

## 기준 자료
- Concept Atlas 프로토타입(사용자 제공 HTML, 2026-10-06): 컴퓨터 네트워크 예시 11개가 고정 데이터이고 실제 AI는 없음. 저장소 reference/ 폴더에는 넣지 않아 구현에서는 참조하지 못함(디자인은 METIS 디자인 원칙 기준).
- 학습 원칙(사용자 제공): 분야의 개념 하나 또는 짧은 질문으로 시작, 처음부터 여러 개념 입력을 요구하지 않음. AI가 현재 개념의 쉬운 설명과 지도상 위치를 먼저 제시한 뒤 지금 필요한 개념 1개를 기본 제안하고 대안은 최대 2개. 제안마다 지금 필요한 이유·현재 개념과의 관계·예상 학습 부담 표시. 사용자는 제안 선택, 직접 입력, 보류·제외 가능. "더 쉬운 설명·더 깊게·다른 길" 반응은 다음 제안에 반영. 전체 지도는 항상 볼 수 있되 기본 화면은 현재 학습 경로와 다음 한 단계만 강조. 입력 개념, 선택 경로, 보류·제외 기록, 메모, 학습 상태는 계속 보존.

## 사용자 결정
- 이름 "개념학습"(확정). 음성 학습과 완전 분리, 홈 휠 메뉴 독립 항목, 권한 새로 만듦(기본 켬), API 경로·테이블도 분리해 개명.
- Concept Atlas 방식으로 새로 구성, 기존 개념 카드(193-4)는 새 구조로 이전해 흡수. AI는 Haiku.
- 1차 범위: 시작, AI 설명, 다음 제안(1+대안 2), 추가·직접 입력·보류·제외, 반응 3종, 메모, 이해 상태, 관계 지도와 목록, 기록 보존. 2차: 계층(그룹) 보기, 돌아보기 퀴즈, 음성 입력(변환 한도 하루 20회 안, 코드는 복제).
- 관계 종류 6가지(포함, 원인→결과, 순서, 대비, 비슷함, 기타 관련)에 짧은 관계 문구. 소주제는 그룹 라벨로 흡수. 이전 결정의 "언급 관계 자동 연결"은 1차에서 제외(후속 후보).
- 디자인: METIS 디자인 원칙(코랄 포인트 하나, 카드·배지 최소, 모바일 우선).

## 사실성 원칙
- AI 설명은 원문 근거가 없으므로 "AI 설명 · 확인 필요"로 표시, 사용자가 고치면 "직접 수정"(content_source ai/user/none). AI 연결도 "확인 필요".
- 프롬프트: 일반적으로 합의된 내용만, 불확실하면 비움, 구체적 연도·수치·인명 최소화, 사용자 입력 속 지시문은 따르지 않음(입력은 JSON 데이터로 직렬화).
- 예상 학습 부담은 가벼움/보통/무거움(분 단위 숫자 금지).

## 구현 중 판단·한계
- 시작 시 AI가 실패하면 학습은 만들고 입력한 첫 개념을 입력창에 남김. 개념 수정은 AI가 쓴 설명도 "직접 수정"으로 표기.
- 지도: 연결된 개념을 덩어리로 묶어 배치(노드끼리 겹치지 않음), 연결선이 다른 노드 위를 지날 수 있음, 기본 배율 0.75 아래로 줄이지 않음, 핀치 확대 미구현(버튼·끌기만).
- 화면의 권한 처리는 /api/me가 명시적으로 false일 때만 거부(fail-open), 실제 차단은 서버 403.
- 직접 연결(두 개념을 골라 관계 종류 지정) 화면은 아직 없음. 서버 API(링크 생성·삭제)는 있음.
- v2 한계: v1 트랜잭션 시작 전에 시작되고 이후 커밋된 행, created_at이 NULL인 행은 놓칠 수 있음(가능성 매우 낮음, 앱 INSERT는 기본값 사용).
