# 디자인 원칙 (이식용 기본판)

METIS-3 앱에서 확정한 디자인 원칙(2026-10-10)을 다른 앱에서도 쓸 수 있게 정리한 문서. 값은 METIS-3의 언어 사전 화면을 기준으로 정했고, 실제 앱 집계(CSS 규칙 1,425개)에서 가장 많이 쓰이던 값을 바탕으로 한다. 앱마다 다른 것은 "앱별로 바꾸는 값"에 따로 적었다.

## 사용법
- 새 앱: 이 문서를 먼저 Claude Code에 읽히고, 아래 CSS 변수를 공용 CSS로 만든 뒤 화면을 만든다.
- 기존 앱: 일괄 치환하지 말고, 새 화면과 수정하는 부분부터 이 원칙에 맞춘다.
- 표기: [확인]은 코드·계산으로 확인한 값, [제안]은 이식하면서 새로 붙인 것이다.

## 핵심 원칙
1. 박스를 줄이고 텍스트 중심으로 만든다. 눌러야 할 주 동작만 채움 버튼으로 표시한다.
2. 한 역할에는 한 값만 쓴다. 같은 역할 값이 둘이면 밝은 쪽을 쓰되, **글자색은 배경 대비 4.5:1 이상**이어야 한다. 미달하면 글자에만 진한 쪽을 쓴다. 면·선·큰 요소는 밝은 쪽을 그대로 쓴다.
3. 다크 모드는 쓰지 않는다.
4. 값은 변수로 정의하고, 화면 CSS에서 직접 색·크기를 쓰지 않는다.

## 색상
| 역할 | 값 | 비고 |
|---|---|---|
| 본문 글자 | #1a1f3c | |
| 보조 글자 | #4a5070 | |
| 비활성 | 투명도 0.35~0.4 | 색을 바꾸지 않는다 |
| 선·구분선·입력 테두리 | #dde2f5 | 1px |
| 페이지 배경 | #f5f7ff | |
| 흰 면 | #ffffff | 카드·입력창 |
| 옅은 파랑 면 | #eef1fb | 보조 면 |
| 포인트(면·선·큰 요소) | #e2583b | 앱별로 바꾸는 값 |
| 포인트(글자·채움 버튼 배경) | #b8442e | 흰 글자와 대비 약 5.4:1 [확인, 계산] |
| 오류·위험 | #dc2626 | 흰 면 위 글자 대비 4.83:1 [확인, 계산] |
| 오류·위험(옅은 면 위 글자) | #B42318 | #dc2626은 옅은 면 위에서 4.0~4.3:1이라 미달. 흰·페이지 바탕 위 글자는 #dc2626 |
| 정답·성공(면·아이콘) | #16a34a | |
| 정답·성공(글자) | #085041 | #16a34a는 글자로 쓰면 대비 약 3.1:1이라 미달 |

- 강조색을 여러 개 쓰는 경우(예: 언어별 색)는 선·태그 면에만 쓰고 글자는 본문색을 쓴다. 주황 #e67e22 글자는 대비 약 2.7:1이다.
- 옅은 면(색 6~12% 투명도) 위에 같은 색 글자를 올리면 대비가 부족할 수 있다. 빨강은 옅은 면 위에서 약 4.0:1이다.

## 글자
| 단계(px) | 용도 |
|---|---|
| 11 | 배지·태그·최소 캡션 |
| 12 | 캡션 |
| 13 | 설명 |
| 14 | 보조(버튼, 발음 등) |
| 15 | 본문 |
| 16 | 입력창 |
| 18 | 섹션 제목, 문제 |
| 22 | 큰 제목 |
| 32 | 큰 숫자 |
| 48 | 특대 숫자 |

- 표에 없는 크기는 용도를 보고 가장 가까운 단계로 쓴다. 9·10px는 쓰지 않는다.
- 굵기: 700(강조), 600, 500, 400. 줄 높이: 1.5(기본), 1.6(긴 글).
- 글꼴: Noto Sans KR + sans-serif. 숫자·로고용으로 Sora를 쓸 수 있다.

## 간격
- 단계(px): 0 · 4 · 8 · 10 · 12 · 16 · 20 · 24.
- 6·14·2px 같은 단계 밖 값은 새로 쓰지 않는다.

## 모서리
- 0: 기본(박스 없음). 10px: 버튼·입력창·검색창·칩. 16px: 카드. 50%: 원형.
- 알약(20px, 999px)과 2·4·8·12·14·24·40px는 쓰지 않는다.

## 그림자
- 하단 내비: `0 -2px 8px` 포인트색 7%.
- 결과 카드: `0 4px 20px` 포인트색 8%.
- 포커스 링: 3px 포인트색 25%.
- 새 그림자 종류를 늘리지 않는다.

## 레이아웃
- 최대 폭 680px, 좌우 여백 16px, 헤더 65px, 제목 바 56px, 하단 내비 78px, 터치 영역 최소 44px, 중단점 460px.
- 모바일 우선. 안전영역(아래쪽)과 `100dvh`를 쓴다.

## 버튼
- 보조 동작: 박스 없는 밑줄 텍스트(높이 44px). 예시 클래스 `.btn.text`.
- 주 동작: 포인트 채움(배경 #b8442e, 흰 글자, 14px, 모서리 10px, 패딩 12px 20px). 예시 클래스 `.btn`.
- 확인창을 거치는 위험 동작: 오류색 텍스트 버튼. 예시 클래스 `.btn.text.danger`.
- 표시용 뱃지는 박스·알약으로 만들지 않는다. 의미상 박스가 필요한 것(진행 막대, 녹음 버튼 등)만 예외 목록으로 관리한다.
- 선택 상태를 박스로 표시하는 컨트롤(속도·모드 선택 등)은 텍스트로 바꾸면 현재 선택이 안 보일 수 있으니 별도 설계한다.

## 입력창
- 흰 면, 1px #dde2f5 선, 모서리 10px, 글자 16px, 포커스는 포인트색 링.

## 그 밖의 규칙 (METIS-3의 이전 원칙 문서에서 이어받음)
- 아이콘은 인라인 stroke SVG만 사용하고, 이모지(국기 포함)는 쓰지 않는다.
- 선택·활성 상태는 색 단독이 아니라 굵기+밑줄(또는 굵기+아이콘 변화) 등 최소 2가지 신호로 표현한다.
- 카운트 표시(뱃지 숫자 등)는 빨간 원형 뱃지 대신 라벨 옆 작은 보조색 숫자로 쓴다.
- 실제 `<button>`, `<a href>`, `<input>`+`<label>`을 쓰고, div에 onClick만 붙이지 않는다.
- 미결: 섹션 라벨을 "작은 대문자 스타일(12px, weight 700, letter-spacing, uppercase, 보조색)"로 통일하던 이전 규칙은 이 원칙의 글자 단계(12px 캡션)와 겹친다. 앱별로 정한다.

## 접근성
- 글자 대비 4.5:1 이상, 터치 영역 44px 이상.
- #dde2f5 선은 흰·페이지 배경과 대비가 1.2~1.3배라 비텍스트 대비 3:1에 못 미친다. 구분선은 장식으로 두고, 입력창 테두리는 개선 후보다.

## 앱별로 바꾸는 값
- 포인트색(#e2583b, #b8442e). 바꿀 때는 글자·채움 버튼용 진한 값이 흰 글자와 4.5:1 이상인지 확인한다.
- 배경 계열(#f5f7ff, #eef1fb)과 글자 계열(#1a1f3c, #4a5070). 바꾸면 보조 글자색 대비를 다시 계산한다.
- 그 밖의 값(글자 단계, 간격, 모서리, 레이아웃)은 앱이 달라도 그대로 쓰는 것을 권장한다.

## CSS 변수 예시 [제안]
```css
:root {
  --color-text: #1a1f3c;
  --color-text-sub: #4a5070;
  --color-line: #dde2f5;
  --color-bg-page: #f5f7ff;
  --color-bg-surface: #ffffff;
  --color-bg-soft: #eef1fb;
  --color-accent: #e2583b;       /* 면·선·큰 요소 */
  --color-accent-strong: #b8442e; /* 글자·채움 버튼 배경 */
  --color-danger: #dc2626;
  --color-danger-ink: #B42318;    /* 옅은 면 위 글자 */
  --color-success: #16a34a;       /* 면·아이콘 */
  --color-success-text: #085041;  /* 글자 */

  --font-sans: "Noto Sans KR", sans-serif;
  --fs-11: 11px; --fs-12: 12px; --fs-13: 13px; --fs-14: 14px; --fs-15: 15px;
  --fs-16: 16px; --fs-18: 18px; --fs-22: 22px; --fs-32: 32px; --fs-48: 48px;

  --sp-0: 0; --sp-4: 4px; --sp-8: 8px; --sp-10: 10px;
  --sp-12: 12px; --sp-16: 16px; --sp-20: 20px; --sp-24: 24px;

  --radius-control: 10px;
  --radius-card: 16px;
  --tap-min: 44px;
  --page-max: 680px;
  --page-gutter: 16px;
}
```

- METIS-3의 tokens.css 실제 변수명은 위 예시와 일부 다르다: --color-bg(페이지 배경), --color-surface(흰 면), --color-surface-2(옅은 면), --color-accent-ink, --color-ok, --color-ok-ink, --color-danger-ink, --card-radius, --radius-ctl 등.

## Claude Code에 줄 때 쓰는 문구 [제안]
"이 앱의 디자인은 첨부한 디자인 원칙 문서를 따른다. 색·글자 크기·간격·모서리는 문서의 변수만 쓰고, 문서에 없는 값이 필요하면 쓰지 말고 먼저 물어본다. 새 박스·알약·그림자를 만들지 않는다."

## 출처와 한계
- 값은 METIS-3의 CSS 집계(선언 횟수 기준)와 언어 사전 화면 값에서 나왔다. 대비비는 WCAG 상대 휘도 공식으로 계산한 값이며 실제 화면에서 눈으로 검증한 것은 아니다.
- 모바일 중심 앱에서 정한 값이다. 데스크톱 중심 앱이나 데이터 표가 많은 화면에는 추가 규칙이 필요할 수 있다.
